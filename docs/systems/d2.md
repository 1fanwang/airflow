# D2

## Service Discovery & curli Integration

### Common Mistakes

**Incorrect**: Using direct HTTPS URLs for LinkedIn internal services.
```
curli "https://grid-user-manager.prod-ltx1.atd.prod.linkedin.com/gridUserManager/users/subseng"
# Error: Could not resolve host — DNS lookup fails
```

**Correct**: Use D2 service discovery with `d2://` scheme.
```
curli -f prod-ltx1 --dv-auth SELF "d2://gridUserManager/users/subseng"
```

### Service Name Format

D2 service names use camelCase, not hyphenated:
- `d2://grid-user-manager` → 404 Invalid D2 service name
- `d2://gridUserManager` → correct

### Finding Service Names

Use `d2state` to list available services in a fabric:
```
d2state -f prod-ltx1 | grep -i "pattern"
```

Known issue: `d2state` may fail with Python import errors in some environments.

### curli Flags for D2

- `-f <fabric>`: Target fabric (e.g., `prod-ltx1`)
- `--dv-auth SELF`: D2 authentication mechanism
