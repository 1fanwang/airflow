# Synthesis

> Part of the workspace knowledge base. See [CLAUDE.md](../../CLAUDE.md) for the navigation map.

Synthesis pages capture living knowledge that doesn't fit neatly elsewhere. Populate them as you encounter new information.

| Page | Summary | How to populate |
|------|---------|-----------------|
| [Open Questions](open-questions.md) | Things still unclear, gaps in understanding, areas to investigate | `## Question title` — what's unclear, why it matters, how to resolve |
| [Contradictions](contradictions.md) | Conflicting information from different sources | `## Contradiction title` — Source A says / Source B says / Best guess / Status |
| [Hypotheses](hypotheses.md) | Working theories — patterns observed but not yet confirmed | `## Hypothesis` — Claim / Evidence for / Evidence against / How to confirm / Confidence |
